4. Cómo llegan los tipos de cambio a la app

La app no se comunica directamente con los proveedores de tipos de cambio. Le pide los datos a un pequeño servidor que operamos: un Cloudflare Worker. Cloudflare, Inc. actúa como nuestro proveedor de alojamiento y encargado del tratamiento. El servidor obtiene los tipos y los guarda en caché, de modo que todos los usuarios reciben los datos de una misma copia compartida.

El servidor usa estas fuentes, en este orden:

  • ExchangeRate-API (open.er-api.com): la fuente principal de tipos de cambio en vivo
  • Currency API (fawazahmed0, servida mediante Cloudflare y jsDelivr): la fuente de respaldo de tipos de cambio en vivo, la fuente de metales preciosos y criptomonedas, y la única fuente de las gráficas de historial de tipos
  • Los tipos de referencia del Banco Central Europeo: se usan solo en el servidor como verificación cruzada. Una tabla de tipos que se desvíe más de 5% del BCE se rechaza. Las cifras del BCE nunca se te muestran.

Nuestro servidor llama a las tres fuentes; tu dispositivo nunca lo hace. Ellas ven solicitudes nuestras, no tuyas. El widget obtiene los tipos de la misma manera.

Una solicitud de tipos de cambio contiene solo un código de moneda. No tiene ningún identificador ni nada de lo que hayas escrito en la app.

Como cualquier servicio web, Cloudflare registra automáticamente registros técnicos de las solicitudes que incluyen la dirección IP desde la que se hizo cada una. Conservamos estos registros solo unos días (Cloudflare Workers Logs). Los usamos únicamente para operar y proteger el servicio. Para limitar los abusos, nuestro servidor cuenta brevemente las solicitudes por dirección IP, y ese conteo no se almacena. No usamos los registros para identificar a nadie, ni para analítica, publicidad o rastreo, y no los compartimos ni los vendemos.

6. Suscripciones y pagos

Apple realiza y procesa las compras mediante App Store. Nunca vemos los datos de tu tarjeta, tu dirección de facturación ni la información de tu cuenta de Apple.

Si compras Pro (una suscripción o Pro de por vida), la app envía a nuestro servidor el comprobante de compra firmado por Apple. El servidor verifica la firma de Apple. Solo conserva el ID de transacción original, el producto, la fecha de vencimiento y si se reembolsó. Cada vez que la app actualiza tu estado de Pro, también envía tu ID de instalación y tu secreto, para que la compra pueda vincularse a esta instalación. Estos datos se vinculan a los ID de instalación que usan la compra, con un máximo de 10 dispositivos por compra. Los usamos solo para decidir cuántas alertas de tipo de cambio puedes tener: 1 en el plan gratuito, hasta 50 con Pro. Estos registros de compra se conservan mientras un dispositivo los use. Eliminar alertas y datos del servidor borra el vínculo de este dispositivo, y el registro mismo si ningún otro dispositivo lo usa. El registro de una compra reembolsada o revocada se conserva, sin vínculo con ningún dispositivo, para que eliminar los datos no pueda deshacer un reembolso.

Apple también notifica a nuestro servidor cuando una suscripción se renueva, vence o se reembolsa (notificaciones del servidor de App Store). Estos avisos no contienen datos de pago. El tratamiento que Apple da a los datos de compra se rige por el Aviso de privacidad de Apple.

También puedes escribirnos a currencyconverter26@outlook.com.
